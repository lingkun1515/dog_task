# DogTaskSim 仿真视频打分准则

本文档定义了多模态 AI 视频审查子 Agent 的打分标准。
审查子 Agent 必须严格按照此准则进行评估，确保客观性和一致性。

---

## 总体判定标准

| 判定 | 得分范围 | 含义 |
|------|---------|------|
| **PASS** | 80-100 | 任务成功完成，机器人行为稳定合理 |
| **HIGH_RISK** | 60-79 | 任务可能成功，但存在明显问题需要关注 |
| **FAIL** | 0-59 | 任务失败或存在严重问题 |

---

## 10 项结构化检查（总分 100 分）

### 1. 行走稳定性 (20 分)

**观察要点**：
- 四足步态是否自然？是否有拖步、滑步？
- 机身是否保持水平？倾斜角是否过大？
- 行进方向是否平滑？是否有突然转向？

**评分标准**：
- 18-20 分：步态自然，机身稳定，转向平滑
- 14-17 分：步态基本正常，偶有轻微晃动
- 10-13 分：步态不自然，有明显晃动或拖步
- 0-9 分：严重不稳，频繁摔倒或剧烈晃动

**扣分项**：
- 拖步/滑步：-2 分/次
- 机身倾斜 > 15°：-3 分
- 突然转向（角度变化 > 30°/步）：-2 分/次

### 2. 导航精度 (15 分)

**观察要点**：
- 是否到达目标位置附近？
- 到达后是否对齐朝向？
- 路径是否合理？是否有不必要的绕路？

**评分标准**：
- 13-15 分：准确到达目标，朝向对齐，路径高效
- 10-12 分：基本到达目标，朝向或路径有小偏差
- 7-9 分：到达目标附近，但偏差较大
- 0-6 分：未到达目标或路径严重偏离

**数值参考**：
- 到达误差 < 0.1m：满分
- 到达误差 0.1-0.3m：扣 2-3 分
- 到达误差 0.3-0.5m：扣 5-8 分
- 到达误差 > 0.5m：扣 10 分以上

### 3. 目标准确性 (10 分)

**观察要点**：
- 到达目标位置后，机械臂是否能检测到目标？
- 目标是否在相机视野内？
- 检测框是否准确？

**评分标准**：
- 9-10 分：目标清晰可见，检测准确
- 7-8 分：目标可见，检测略有偏差
- 5-6 分：目标部分可见，检测不稳定
- 0-4 分：目标不可见或检测失败

### 4. 机械臂运动 (15 分)

**观察要点**：
- IK 求解是否成功？
- 机械臂运动是否平滑？
- 是否有奇异姿态或关节限位问题？

**评分标准**：
- 13-15 分：运动平滑，无奇异姿态
- 10-12 分：运动基本正常，偶有抖动
- 7-9 分：运动不平滑，有明显抖动或卡顿
- 0-6 分：IK 失败或运动严重异常

**扣分项**：
- 关节抖动：-2 分/次
- 奇异姿态：-3 分
- 关节限位触碰：-2 分

### 5. 抓取执行 (20 分)

**观察要点**：
- 夹爪是否正确闭合？
- 是否成功抓起目标物体？
- 提起过程中物体是否掉落？

**评分标准**：
- 18-20 分：抓取成功，物体稳定，提起顺利
- 14-17 分：抓取成功，但物体有轻微晃动
- 10-13 分：抓取部分成功，物体滑落或未完全闭合
- 0-9 分：抓取失败，物体掉落或未接触

**关键帧检查**：
- 接近阶段：夹爪是否对准目标？
- 闭合阶段：夹爪是否完全闭合？
- 提起阶段：物体是否稳定？

### 6. 返航能力 (10 分)

**观察要点**：
- 抓取后是否能返回起点？
- 返航路径是否合理？
- 返回后是否对齐初始朝向？

**评分标准**：
- 9-10 分：顺利返回，路径合理，朝向对齐
- 7-8 分：基本返回，路径或朝向有小偏差
- 5-6 分：返回困难，路径绕远或朝向偏差大
- 0-4 分：未返回或返回失败

### 7. 碰撞检测 (5 分)

**观察要点**：
- 是否有明显的穿模现象？
- 机器人是否与障碍物碰撞？
- 机械臂是否与机身碰撞？

**评分标准**：
- 5 分：无碰撞
- 3-4 分：轻微接触，不影响任务
- 1-2 分：明显碰撞，影响任务
- 0 分：严重碰撞或穿模

### 8. 整体协调性 (5 分)

**观察要点**：
- 底盘和机械臂运动是否协调？
- 各阶段切换是否平滑？
- 整体任务流程是否顺畅？

**评分标准**：
- 5 分：高度协调，切换平滑
- 3-4 分：基本协调，偶有卡顿
- 1-2 分：协调性差，切换生硬
- 0 分：严重不协调

### 9. 异常情况 (扣分项)

| 异常情况 | 扣分 | 说明 |
|---------|------|------|
| 摔倒 | -50 分 | 机器人完全倒地 |
| 卡死 | -30 分 | 机器人停止响应 |
| 异常抖动 | -10 分 | 持续剧烈晃动 |
| 物体掉落 | -15 分 | 抓取后物体掉落 |
| 碰撞 | -5 分 | 与障碍物碰撞 |
| 超时 | -10 分 | 任务超时未完成 |

### 10. 改进建议

审查子 Agent 必须提供 3-5 项优先改进方向，格式如下：

```json
{
    "improvement_suggestions": [
        "优先级1：具体改进方向",
        "优先级2：具体改进方向",
        "优先级3：具体改进方向"
    ]
}
```

**建议分类**：
- 导航优化：路径规划、速度控制、朝向对齐
- 抓取优化：IK 求解、夹爪控制、物体检测
- 稳定性优化：步态调整、PD 参数、平衡控制
- 碰撞避免：障碍物检测、路径规划、安全距离

## 审查流程

### 步骤 1：整体观察

观看完整视频，了解任务流程和整体表现。

### 步骤 2：关键帧检查

检查以下关键帧：

1. **起始状态**：机器人初始姿态是否正常？
2. **行走阶段**：步态是否稳定？
3. **到达目标**：是否准确到达？
4. **抓取准备**：机械臂是否正确展开？
5. **抓取执行**：夹爪是否对准目标？
6. **抓取成功**：物体是否被成功抓起？
7. **返航阶段**：是否顺利返回？
8. **结束状态**：机器人是否稳定？

### 步骤 3：逐项打分

按照 10 项检查逐项打分，记录扣分原因。

### 步骤 4：综合判定

根据总分判定：
- 80-100 分：PASS
- 60-79 分：HIGH_RISK
- 0-59 分：FAIL

### 步骤 5：生成报告

输出结构化 JSON 报告，包含：

```json
{
    "overall_verdict": "PASS" | "HIGH_RISK" | "FAIL",

```

## 注意事项

### 客观性要求

- 审查子 Agent 必须独立评估，不受主 Agent 影响
- 只依据视频内容打分，不参考代码日志
- 扣分必须有明确理由，不能主观臆断

### 一致性要求

- 同类问题必须使用相同扣分标准
- 不同视频的打分必须可比较
- 打分标准不能随意调整

### 特殊情况处理

- 视频模糊或视角不佳：在报告中说明，但不因此降低标准
- 任务未完成：根据实际完成情况打分，不假设"如果继续会成功"
- 异常情况：详细记录，作为扣分依据

## 与数值分析器的关系

视频审查和数值分析器是互补的：

- **视频审查**：提供直观的行为观察，发现代码无法捕获的问题
- **数值分析器**：提供精确的数值指标，支持量化评估

**冲突处理**：

- 若视频审查与数值分析结果冲突，以数值和视频为准
- 若视频模糊不清，以数值分析结果为准
- 若数值缺失，以视频审查结果为准

**最终判定**：

- PASS：视频审查 PASS 且数值分析无严重问题
- HIGH_RISK：视频审查 HIGH_RISK 或数值分析有警告
- FAIL：视频审查 FAIL 或数值分析有严重问题
