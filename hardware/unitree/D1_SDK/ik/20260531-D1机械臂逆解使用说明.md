# 20260531-D1 机械臂逆解使用说明

把"目标坐标"解算成 D1 机械臂可下发的"关节角度参数", 并通过 DDS 控制机械臂完成
固定/可变位置的抓取-放置任务(方案 B: 坐标 + 逆运动学)。

---

```

## 3. 坐标系与约定

- 坐标系: `base_link`(机械臂底座), **x 向前, z 向上**, 单位米。
- 角度: 命令行输入用**度**, 下发给机械臂的也是度(对应 DDS 的 `angle0~angle5`)。
- 关节映射: URDF 的 `Joint1~Joint6` 依次对应 DDS 的 `angle0~angle5`; `angle6` 是夹爪。
- 抓取姿态用**接近方向向量**描述(夹爪靠近物体的方向):
  - `0 0 -1` = 从正上方竖直向下抓(最常用);
  - `1 0 0` = 水平从前方抓。
  - 只约束接近方向, 绕夹爪轴的自转自由 —— 对圆柱形瓶子最合适, 也最容易求出解。

## 4. 你需要输入的信息

针对你的场景(瓶子在前方, 放到收纳框):

| 信息 | 说明 | 示例 |
|---|---|---|
| 瓶子位置 `--bottle x y z` | 瓶子**抓取点**在底座系下的坐标(米) | `0.3 0 0.05` |
| 收纳框位置 `--basket x y z` | 框内放置点坐标(米) | `0.1 0.25 0.1` |
| 接近方向 `--approach-dir` | 夹爪朝向, 默认顶部向下 | `0 0 -1` |
| 接近高度 `--approach` | 抓取/放置点正上方的预备高度(米) | `0.08` |

> 瓶子位置后续会变, 只要改 `--bottle` 的三个数即可, 无需改代码。

## 5. 快速使用

### 5.1 单点逆解(坐标 -> 关节参数)

```bash
cd hardware/unitree/D1_SDK/ik
./d1ik.sh solve --xyz 0.3 0 0.13 --approach-dir 0 0 -1
```

输出示例:
```
关节角(度) angle0~angle5 = -15.0, 25.3, 23.5, -95.1, 85.5, -41.1
位置误差 = 0.00 mm, 姿态误差 = 0.00°
关节在限位内: True, 可达: True
DDS 指令: {"seq":4,"address":1,"funcode":2,"data":{"mode":1,"angle0":-15.0,...}}
```

### 5.2 抓取-放置全流程规划

```bash
./d1ik.sh grasp --bottle 0.3 0 0.05 --basket 0.1 0.25 0.1 --out grasp_seq.json
```

会自动规划并逐点逆解以下 8 个动作(全部校验可达性), 并把指令序列写入 `grasp_seq.json`:

```
回零位 -> 抓取上方(张爪) -> 抓取点 -> 闭合夹爪 -> 提起
       -> 框上方 -> 框内放置 -> 松开夹爪 -> 抬起退回
```

### 5.3 直接下发到机械臂

确认机械臂上电、网线连通(默认网段 192.168.123.x), 加 `--send`:

```bash
./d1ik.sh grasp --bottle 0.3 0 0.05 --basket 0.1 0.25 0.1 --send
```

也可单独发任意指令:

```bash
../build_linux/arm_cmd_send '{"seq":4,"address":1,"funcode":7}'      # 回零
../build_linux/arm_cmd_send '<solve输出的DDS指令>'                    # 走到某位姿
../build_linux/arm_cmd_send '<JSON>' eth0                            # 指定网卡
```

## 6. 真机标定结果(已于 20260531 联机验证)

逆解算法已用 FK->IK 自洽测试验证(50/50 通过, <1mm), 并在真机上逐关节标定确认:

| 项目 | 标定结果 | 说明 |
|---|---|---|
| 工具轴 `tool_axis` | **X 轴(0)** | 夹爪沿法兰 X 轴伸出(实测: 零位时末端朝前)。**这是关键**, 早期误设为 Z 轴导致姿态完全错误。 |
| TCP 偏移 `--tcp` | **≈0.12m(沿法兰X)** | 法兰到夹爪夹持中心, 已验证位置正确; 如需更准可用卷尺复核。 |
| 关节符号 `--sign` | **全部 +1** | J0/J1/J2/J4 实测方向均与 URDF 一致; J3/J5(腕滚转)在朝下抓取时为 0, 朝向验证正确。 |
| 关节零位 `--offset` | **全部 0** | 真机零位与 URDF 零位一致(大臂朝天、小臂前伸)。 |
| 夹爪 angle6 | **越大越张开, 范围0~50** | angle=50 全开(~65mm), angle=0 接近闭合(~15mm缝); 近似 缝隙mm≈15+angle。夹住值≈瓶径-20(40mm瓶→约20)。`solve_ik.py` 常量已设好。 |
| 有线网卡 | **enx6c1ff765a912** | 本机 192.168.123.50, 机械臂 192.168.123.100。 |

> 验证记录: 移动到瓶子上方 (0.25,0,-0.12) 顶部向下, 实测末端落点与朝向均正确。
> 若更换机械臂或重新装配夹爪, 按上表逐项用 `safe_move_to` 单关节试动重新核对。

## 6.5 拖动示教抓取(臂展边缘/坐标难对准时最可靠)

当目标在臂展边缘(如本例收纳框 0.48m), 纯坐标 IK 会解出扭曲解、接近点不可达。
此时改用**拖动示教**: 手动把机械臂摆到目标位姿, 读回关节角, 再回放。

### 工作流(已验证可成功抓放)

```bash
cd hardware/unitree/D1_SDK/build_linux
I=enx6c1ff765a912

# 1) 全部卸力(务必先扶住机械臂!) 然后手动摆到"夹爪正好抓住瓶子"的位姿
./arm_cmd_send '{"seq":1,"address":1,"funcode":5,"data":{"mode":0}}' $I

# 2) 读取并记下当前 7 个关节角(servo0~6) —— 这是抓取示教角
timeout 2 ./get_arm_joint_angle 2>/dev/null | grep servo0_data | tail -1

# 3) 手动移到"放入收纳框"的位姿, 再次读取记下 —— 这是放置示教角

# 4) 重新使能, 让机械臂撑住(然后才能松手)
./arm_cmd_send '{"seq":1,"address":1,"funcode":6,"data":{"power":1}}' $I   # 上电
for id in 0 1 2 3 4 5 6; do \
  ./arm_cmd_send "{\"seq\":1,\"address\":1,\"funcode\":4,\"data\":{\"id\":$id,\"mode\":1}}" $I; done  # 逐关节使能

# 5) 回放抓放: 抓取点/放置点用示教角, 自动加"正上方->垂直下降", 抓取段慢、转运段快
cd ../ik
./d1ik.sh teach --grasp-joints <抓取6角> --place-joints <放置6角> \
  --approach 0.07 --step 6 --dt 50 --slow-step 1.5 --slow-dt 110 --send-safe
```

> **关键经验**: 回放会精确回到"示教时的关节角", 所以**瓶子必须在示教时的原位**才能抓中。
> 手动重新摆瓶子很难每次对齐 —— 最可靠的做法是 **针对瓶子当前位置重新示教(步骤1-4), 然后立即回放(步骤5)**, 中间不要再移动瓶子。
> 长期方案应接入视觉获取瓶子实时坐标, 再用 `solve/grasp` 自动解算(本工具已就绪)。

### teach 参数

- `--grasp-joints / --place-joints`: 6 个示教角(度), 即 servo0~servo5。
- `--approach`: 抓取点正上方接近高度(米, 默认 0.07)。
- `--step/--dt`: 转运段速度(步长度/间隔ms, 越大/越小越快)。
- `--slow-step/--slow-dt`: 抓取下降段速度(默认 1.5°/110ms, 慢而稳)。
- `--send-safe`: 走 `safe_move_to` 慢速插值执行(真机推荐)。

### 安全须知

- **严禁** funcode 5 卸力时松手不扶 —— 机械臂会失去保持力垮落。
- 卸力示教 -> 重新使能瞬间, J 轴可能因重力短暂下垂(实测 J1 一度到 100°), 属正常, 使能后即锁定。
- `safe_move_to` 自带越界护栏与到位等待(随运动幅度自适应), 全程慢速可急停。

## 7. 选择 URDF(确认硬件型号)

默认使用 `D1-550`(`urdf/D1-550 URDF/.../d1_550_description.urdf`), 对应文档 550mm 臂展规格。
若你的实物是另一款, 用 `--urdf` 指定:

```bash
./d1ik.sh solve --xyz 0.3 0 0.2 --approach-dir 0 0 -1 \
  --urdf "../../../../urdf/D1 URDF/d1_description/urdf/d1_description.urdf"
```

两个 URDF 关节限位一致, 但连杆尺寸/坐标系定义不同, **务必用与实物一致的那个**, 否则解算会有系统偏差。

## 8. 算法说明

- **正运动学**: 逐关节按 URDF 的 `origin(xyz+rpy)` 和 `axis` 累乘齐次变换, 末端加 TCP 偏移。
- **逆运动学**: `scipy.optimize.least_squares`(信赖域 + 关节限位 bounds), 多随机初值重启避免局部极小。
  - 残差 = 位置误差(3) [+ 接近方向误差(3) 或 完整姿态误差(3)]。
  - 抓取序列中, 用上一路点的解作为下一点初值, 保证关节轨迹连续、避免跳变。
- **可达性判定**: 位置 <5mm 且接近方向 <~3° 且 6 关节均在限位内, 才标记为"可达"。
